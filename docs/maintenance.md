# 文档维护

本页面向维护者。用户入口见 [入门](guide/index.md)。

## 内容来源与更新

sources.json 记录镜像页面的源码仓库、文件与核对提交。镜像正文保留原文的详细参数和限制；链接指向对应源码文件。更新组件后同步其 README、语言指南和本站镜像，刷新核对日期和基线。当前复制不代表自动同步。

README 面向用户：用途、安装、完整最小示例、支持/不支持、文档入口、许可证和免责声明。构建、CI、发布、历史计划保留在各仓库维护者文档。开发分支新增功能必须明确未发布；无法确认的授权不得补写成已确认。

## 发布检查

运行 npm ci、npm run check:links、npm run docs:build；检查首页、侧边导航、移动布局、搜索和代码块。GitHub Pages 工作流只在 main 推送发布，PR 只检查。必须保持组织站点 base 为 /。构建失败不部署。

新增页面要加入导航，示例 URL 标明占位性质。不要无依据扩大协议范围、系统兼容性、完整浏览器一致性或安全承诺。
